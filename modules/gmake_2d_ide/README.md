# GMake 2D IDE Module (Bootstrap)

This module is the first step of the Godot fork customization.

## Implemented in bootstrap

- Enforces 2D-first editor startup behavior.
- Hides the 3D main-screen button.
- Adds a 2D template quick-start panel in canvas editor side-left.
- Ships starter template metadata for follow-up generation tools.

## Next planned steps

- Add InputMap preset application per template.
- Add block-system panel integration.
- Add Python daemon bridge UI controls.
